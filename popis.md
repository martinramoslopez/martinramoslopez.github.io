# Kvíz: Identifikace a řešení problémů

Jednoduchý interaktivní kvíz v HTML + CSS + JavaScript zaměřený na **systematické řešení technických problémů** (troubleshooting) u počítačů – hardware vs software, diagnostika, prevence, ověření a dokumentace.

Perfektní jako výukový materiál pro IT kurzy, školení správců sítí, SOŠ/SŠ informatika nebo jen pro vlastní procvičení.

## Co kvíz obsahuje

- 6 otázek s jednou správnou odpovědí (A/B/C/D)
- Moderní hexagon-ish / dark-mode styl (tmavý motiv, zaoblené karty, hover efekty)
- Po odeslání ukáže:
  - celkové skóre (např. 5/6 = 83 %)
  - u každé otázky – správně/špatně + vysvětlení proč
- Jednoduchý JavaScript – žádné frameworky, běží i na starším prohlížeči
